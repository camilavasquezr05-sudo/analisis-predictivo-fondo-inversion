# analisis-predictivo-fondo-inversion
Análisis en R para predecir el retorno mensual del ETF CFIETFCC mediante indicadores macroeconómicos de Chile y EE.UU. y el tipo de cambio USD/CLP. Compara regresiones, árboles de decisión y bosques aleatorios con reglas simples para evaluar la predicción del retorno y su dirección.
